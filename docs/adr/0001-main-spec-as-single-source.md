# 0001 主规范为唯一硬规则

中文技术文档写作规范存在多个互相冲突的来源（本仓库规则、sparanoid 指北、TapTap/LeanCloud 指南、GB/T 15835-2011、GB 3100-1993），在直角引号、中数空格、全角数字等议题上各有取舍。本技能决定：以本仓库 6 个规则模块（references/rules.md）为唯一硬规则，冲突处以仓库为准，外部指南只作溯源注记（references/provenance.md），不进入检查逻辑；用户特殊需求通过例外清单机制（SKILL.md 第 2 步）表达，而非切换规则来源。否则一次校对可能因"用哪本指南"而输出不同结果，破坏技能的可预测性。
